## Como visualizar localmente

Abra os `index.html` no browser, ou sirva a pasta:

```bash
npx --yes serve docs/pitch
```

## GitHub Pages (opcional)

Para republicar os pitches a partir deste repo:

1. Settings → Pages → Source: Deploy from a branch
2. Branch: `main`, pasta `/docs`
3. URLs esperadas:
   - `/pitch/produto/`
   - `/pitch/tese-mercado/`

O [`index.html`](./index.html) nesta pasta lista os dois decks.
